# MCP 服務器

這個項目包含多個 MCP（Model Context Protocol）服務器，每個服務器提供不同的功能模組。

## 目錄功能簡述

### `date`

時間和時區處理服務，提供日期和時區相關的功能：
- 獲取今日日期（支援自定義格式）
- 獲取特定時區的當前日期時間
- 在不同時區間轉換日期時間
- 獲取可用時區列表
- 按地區獲取常用時區
- 驗證日期是否為今天

### `excel`

Excel 檔案處理服務，提供各種 Excel 檔案操作能力：
- 建立、讀取、寫入 Excel 檔案
- 工作表管理（新建、列表、刪除、重命名）
- 儲存格、行、列、區域數據讀寫
- 儲存格範圍合併
- CSV 檔案匯入匯出功能

### `filesystem`

文件系統操作服務，提供全面的檔案和目錄管理功能：
- 檢查文件/目錄存在狀態
- 文件讀寫、創建和刪除
- 文件複製和移動操作
- 目錄建立與內容列舉
- 文件元數據和詳細資訊獲取

### `google-drive`

Google Drive 檔案操作服務，提供與 Google Drive 互動功能：
- 檔案建立、上傳、下載、更新、移動、重命名、刪除
- 建立資料夾和管理檔案結構
- 檔案搜尋（全域或指定目錄）和元數據獲取
- 依檔名查詢檔案 ID、檢查檔案是否存在

### `gmail`

Gmail 郵件操作服務，提供郵件收發與管理功能：
- 寄送郵件（支援副本 CC 與多個附件）
- 列出收件匣未讀郵件
- 使用 Gmail 搜尋語法查詢郵件
- 依郵件 ID 獲取郵件詳細內容
- 標記郵件為已讀／未讀
- 刪除郵件

### `google-map`

Google Maps Places API 地點查詢服務，提供地點搜尋與詳情功能：
- 文字查詢搜尋地點，可依評分、價位等級、地點類型過濾
- 依座標與半徑搜尋附近地點
- 地點名稱自動完成建議
- 依 Place ID 獲取地點詳細資訊
- 獲取地點照片
- 查詢可用的 field mask 欄位說明

### `cwa-tw`

台灣中央氣象署氣象監測服務，提供即時氣象與地震數據存取功能：
- 查詢台灣各縣市對應的 API 代號
- 獲取全台鄉鎮天氣預報（時間區間不得超過 24 小時）
- 獲取指定區域地震觀測資料（時間區間不得超過 36 小時）

### `tw-stock`

台灣證券交易所（TWSE）開放資料服務，提供上市公司與市場數據查詢功能：

**公司資訊**
- 公司基本資料、重大訊息公告、每日重大訊息
- 月營收、股利分派、股權結構、財務資料
- 銀行業資產負債表

**ESG 資訊**
- 永續報告書、功能性委員會、供應鏈管理、風險管理及其他 ESG 揭露

**市場行情**
- 大盤指數、5 分鐘指數（歷史與即時）
- 個股每日成交資訊、每日均價、熱門前 48 檔個股
- ETF 排行、估值指標（本益比、殖利率等）
- 融資融券餘額、融資買進餘額、融券賣出餘額
- 外資持股類別與前 20 大持股

**市場動態**
- 新聞列表、市場事件列表

此模組另提供 MCP Prompt 範本，涵蓋股息投資策略、外資投資分析、投資篩選、市場熱點監控與個股趨勢分析。

## 技術架構

所有服務均為獨立的 Gradle 專案，使用 Kotlin 2.4.0 開發，基於 Quarkus 框架與 `quarkus-mcp-server-stdio` 擴充套件，透過 MCP 通訊協議與其他系統互動，可獨立部署為 uber-jar。執行環境需求為 Java 21。
